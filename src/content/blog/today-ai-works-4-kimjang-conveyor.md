## 무엇을 만들었나

컨베이어 벨트로 배추가 흘러온다. **작업 구역**에 들어온 배추를 소금(A) → 양념(S) → 담기(D) 순서로 처리해 김치통에 넣는다. 순서를 틀리거나 놓치면 할머니 잔소리 게이지가 한 칸 오르고, 다섯 칸이 차면 끝이다. 30초마다 벨트가 빨라진다. **도전 #4**다.

- 게임: [김장 컨베이어 대소동](https://today-ai-works.pages.dev/games/kimjang-conveyor/)

## AI에 넣은 시작 프롬프트

```text
HTML/CSS/JS 한 파일로 된 브라우저 미니게임 "김장 컨베이어 대소동"을 만들어줘. 외부 라이브러리나 이미지 없이 Canvas 2D와 이모지만 사용해.

[게임 규칙]
- 화면 중앙에 가로로 컨베이어 벨트가 있고, 배추(🥬)가 왼쪽에서 오른쪽으로 일정 간격으로 흘러온다.
- 각 배추는 상태가 있다: 생배추 → 절임(A키) → 양념(S키) → 통 담기(D키) 순서로 처리해야 한다.
- 벨트 오른쪽 1/3 지점에 "작업 구역"이 있고, 구역 안에 있는 가장 앞 배추에만 키 입력이 적용된다.
- 상태별로 배추 색을 다르게 표시(생: 연두, 절임: 흰빛, 양념: 빨강). 완료되면 김치통 쪽으로 튀어가는 애니메이션.
- 순서가 틀리거나, 완료되지 않은 배추가 오른쪽 끝을 벗어나면 "할머니 잔소리 게이지"가 20% 오른다. 100%면 게임 오버.
- 연속 성공 시 콤보 카운트, 5콤보마다 점수 배율 +0.5.
- 30초마다 벨트 속도 15% 증가. 60초 이후엔 무(🥕 대신 흰 원으로 표현한 무)가 섞여 나오며, 무는 S키 한 번만 누르면 완료.
- 실수할 때 화면 상단에 할머니 말풍선 대사를 무작위로 1.5초 표시 ("간이 하나도 안 뱄잖니!", "양념은 골고루!" 등 5개 이상).

[UI]
- 상단: 점수, 콤보, 잔소리 게이지 바, 경과 시간
- 시작 화면(조작법 안내 + 시작 버튼)과 게임 오버 화면(담근 포기 수, 등급: 새내기/살림꾼/동네 고수/김장 장인, 다시하기 버튼)
- 배경은 겨울 마당 느낌으로, 눈송이가 천천히 내리게.
- 실수 시 화면 살짝 흔들림, 성공 시 짧은 효과음(Web Audio API로 생성).

코드는 requestAnimationFrame 기반 게임 루프로 깔끔하게 구조화하고, 주요 수치(속도, 간격, 게이지 증가량)는 상단 상수로 빼서 조절하기 쉽게 해줘.
```

## 프롬프트와 다르게 정한 것

| 프롬프트 | 바꾼 것 | 이유 |
|---|---|---|
| 무는 60초부터 | **30초부터** | 함정을 더 일찍 만나게 하려고 |
| 함정은 무 하나 | **쪽파 추가** (60초부터) | 쪽파는 속 재료라 건드리면 실수. "누르지 않기"도 판단하게 |
| 휴대폰 조작 없음 | 아래에 큰 버튼 세 개 | 엄지가 닿기 쉽게 화면 아래쪽에 배치 |
| 실수 처리만 있음 | 하나 완성할 때마다 잔소리 2% 회복 | 잘하는 사람이 오래 버틸 수 있게 |
| — | 처음 20초는 누를 키를 재료 위에 표시 | 처음 하는 사람도 규칙을 바로 익히게 |

배추, 무, 쪽파는 이모지 대신 도형으로 직접 그렸다. 이모지는 색을 바꿀 수 없어서, 생배추(연두) → 절임(흰빛) → 양념(빨강)으로 색이 변하는 걸 보여 주려면 직접 그려야 했다.

확장 아이디어 중 **김장 일지**(최고 기록, 올해 누적 포기, 오늘 담근 포기를 브라우저에 저장)를 넣었다. 2인 협동 모드는 넣지 않았다.

## 등급 기준은 봇으로 정했다

프롬프트에는 등급 이름(새내기 · 살림꾼 · 동네 고수 · 김장 장인)만 있고, 몇 포기부터인지는 없었다. [지난 글](/blog/today-ai-works-3-suyuk-thief/)처럼 봇으로 재서 정했다.

봇은 네 가지 값으로 실력을 흉내 낸다.

- 반응 시간: 배추가 구역에 들어온 뒤 첫 키를 누르기까지
- 키 간격: 키와 키 사이 시간
- 실수 확률: 순서를 틀릴 확률
- 함정 확률: 무를 배추로 착각하거나 쪽파를 건드릴 확률

실력마다 40판씩 돌린 결과(중앙값)다.

| 봇 실력 | 버틴 시간 | 담근 포기 |
|---|---|---|
| 느림 | 52초 | 22포기 |
| 보통 | 109초 | 50포기 |
| 잘함 | 187초 | 99포기 |
| 고수 | 257초 | 159포기 |

그래서 등급을 이렇게 정했다.

| 등급 | 담근 포기 |
|---|---|
| 🐣 김장 새내기 | 0~24 |
| 🧤 살림꾼 | 25~54 |
| 🏅 동네 고수 | 55~99 |
| 👑 김장 장인 | 100 이상 |

처음 정한 기준(15 · 30 · 50포기)은 보통 봇만 돼도 김장 장인이 나와서 너무 낮았다. 숫자를 보고 나서야 알았다.

## 영상: 15초 안에 "빨라지는 맛"을 보여 주기

이 게임은 1분이 넘어야 진짜 재미(빠른 벨트, 함정)가 나온다. 15초 영상에 다 담으려고 중간에 시간을 건너뛰었다.

1. 처음 5초: 봇이 척척 처리하고, 5콤보에 할머니가 "옳지, 손맛 좋다!"
2. 「⏩ 1분 뒤」 표시와 함께 게임 시각을 90초로 옮김 → "속도 UP!" 배너, 무 · 쪽파 등장
3. 봇이 함정에 연달아 속아서 잔소리 게이지가 꽉 참 → "됐다, 내가 할란다!"
4. 등급 카드(살림꾼 36포기)와 "김장 장인 될 수 있어?"

### 효과음도 영상에 넣었다

[2편](/blog/today-ai-works-2-snow-music-box/)에서는 기록한 음을 Node.js에서 같은 공식으로 다시 합성했다. 이번에는 더 간단한 방법을 썼다. 브라우저에는 소리를 스피커로 내지 않고 파일로 만들어 주는 **OfflineAudioContext**가 있다. 게임이 쓰는 효과음 함수를 그대로 OfflineAudioContext에 넣어 15초짜리 소리를 만들었다. 공식을 두 번 쓰지 않아도 되니 게임 소리와 영상 소리가 어긋날 일이 없다.

### 막힌 점

| 막힌 점 | 해결 |
|---|---|
| 첫 영상은 15초가 끝날 때까지 게임 오버가 안 났다 | 시간을 건너뛴 뒤 봇의 실수 확률을 올리고 시작 잔소리를 40%로 둠 → 10.5초에 게임 오버 |
| 「손맛 보너스 ×1.5」 글자가 할머니 말풍선과 겹침 | 위쪽 콤보 칸에 이미 ×1.5가 빨갛게 보여서 이 글자는 뺌 |
| 「⏩ 1분 뒤」가 「속도 UP!」 배너와 겹침 | 1분 뒤 표시를 아래쪽으로 내림 |
| 효과음이 작게 들림 | ffmpeg로 소리를 키우고 찢어지지 않게 리미터를 걺 |

## 배운 점

- 등급처럼 "몇부터 잘하는 건지"는 만든 사람이 정하기 가장 어려운 값이다. 봇 분포를 보고 정하니 근거가 생겼다.
- 영상은 게임을 처음부터 보여 줄 필요가 없다. 재미있는 구간으로 건너뛰되, 「1분 뒤」처럼 건너뛰었다고 솔직하게 표시했다.
