## AI에 넣은 시작 프롬프트

```text
HTML/CSS/JS 한 파일로 "2026 나의 연말 영수증"이라는 개인 소개 페이지를 만들어 줘.

디자인:
- 화면 가운데 폭 360px 정도의 흰 감열지 영수증, 배경은 따뜻한 어두운 회색
- 위아래 테두리는 clip-path로 지그재그 처리, 종이에 아주 옅은 그림자와 질감
- 글꼴은 Google Fonts 'Nanum Gothic Coding', 모든 텍스트는 고정폭 정렬

내용 구조 (JS 배열 데이터로 관리해서 내가 쉽게 고칠 수 있게):
- 상단: 가게 이름 대신 내 이름, "영업시간 2026.01.01 ~ 2026.12.31", 영수증 번호
- 카테고리(만든 것 / 배운 것 / 다녀온 곳 / 소소한 성취)별 항목:
  "항목명 ×수량 ........ 값" 형식으로 점선 자동 채움 정렬
- 카테고리별 소계, 맨 아래 "총 성장 합계"와 한 줄 감사 문구
- 마지막에 가짜 바코드 이미지(CSS로 세로줄) — 클릭하면 내 이메일/GitHub 링크로 이동

인터랙션:
- 스크롤하면 각 줄이 IntersectionObserver로 위에서부터 한 줄씩 타이핑되듯 나타남
- 줄이 출력될 때 Web Audio API로 합성한 짧은 프린터 "치익" 소리 (음소거 버튼 포함, 기본은 꺼짐)
- 하단 "✂️ 뜯어가기" 버튼: 절취선이 찢어지며 아래로 떨어지고 연락처 카드가 나타남
- 우상단 "❄️ 첫눈" 토글: Canvas로 눈이 내리고, 영수증 윗부분에 살짝 쌓이는 효과
- "인쇄하기" 버튼: @media print로 영수증만 깔끔하게 출력

샘플 데이터는 개발자 지망생 기준으로 그럴듯하게 채워 주고, 코드에 주석으로 수정 위치를 표시해 줘.
```

## 내 소개 페이지 대신 "누구나 만드는 도구"로

프롬프트는 **내** 소개 페이지다. 그런데 이걸 공개 사이트에 그대로 올리면 이름, 이메일, 연락처가 누구나 보는 페이지에 나간다. 그래서 방향을 바꿨다.

- 견본은 가상의 개발자 지망생 「김새해」로 채웠다.
- 방문자가 **「내 영수증 만들기」**에서 자기 항목을 적고 바로 다시 출력할 수 있다. 확장 아이디어 "친구도 자기 영수증을 만들어 공유"를 기본 기능으로 넣은 셈이다.
- 공유 링크는 [5편](/blog/today-ai-works-5-kimjang-split/) 정산기처럼 주소의 `#` 뒤에 내용을 담는다. 서버에 저장하지 않는다.
- 공유 링크로 연락처 주소에 이상한 값(예: `javascript:`로 시작하는 주소)이 들어와도 눌리지 않게, `https://` · `http://` · 메일 주소만 받는다.

입력은 한 줄에 하나씩 이렇게 적는다.

```text
개인 블로그 x1 / 글 24편
파이썬 기초 x1 / 120시간
아침 운동 x87 / 87일
```

## 한글과 영문이 섞여도 점선 맞추기

영수증은 오른쪽 끝이 딱 맞아야 영수증 같다. 고정폭 글꼴에서 영문 · 숫자는 1칸, 한글은 2칸을 차지한다. 그래서 한 줄을 **40칸**으로 정하고 이렇게 맞췄다.

1. 글자마다 실제로 그려지는 폭을 재서 몇 칸인지 센다 (한 번 잰 글자는 기억해 둔다).
2. `왼쪽 글자 + 빈칸 + 점선 + 빈칸 + 오른쪽 글자`가 정확히 40칸이 되게 점선 개수를 정한다.
3. 항목 이름이 너무 길면 이름을 한 줄에 쓰고, 다음 줄에 점선과 값을 쓴다.
4. 글자 크기는 화면 폭에 따라 "40칸이 영수증 안쪽 폭에 꼭 맞게" 계산한다.

글자 폭을 재지 않고 "한글은 2칸"이라고 정해 두면 `·`이나 `~` 같은 기호에서 어긋날 수 있다. 직접 재는 쪽이 안전했다.

```text
고정폭 글꼴로 영수증처럼 "항목명 ........ 값"을 정렬하고 싶어. 한 줄은 {40}칸이야.
- 한글과 영문 · 숫자 · 기호가 섞여도 오른쪽 끝이 맞게, 글자마다 실제 폭을 canvas measureText로 재서 칸 수를 계산해 줘
- 이름이 길면 줄을 나눠서 다음 줄에 점선과 값을 써 줘
- 화면 폭에 맞춰 한 줄 {40}칸이 꼭 들어가는 글자 크기를 계산해 줘
```

## 그 밖에 만든 것

| 기능 | 어떻게 |
|---|---|
| 지그재그 테두리 | clip-path로 위아래를 톱니 모양으로 자르고, 감싼 상자에 `drop-shadow`를 줘서 잘린 모양대로 그림자 |
| 한 줄씩 출력 | 화면에 들어온 줄부터 위에서 차례로, 왼쪽부터 칸 단위로 드러나게 |
| 프린터 소리 | 잡음을 짧게 잘라 높은 주파수만 걸러 "치익". 기본은 꺼짐 |
| 뜯어가기 | 절취선 아래 조각이 기울며 떨어지고, 그 자리에 연락처 카드 |
| 첫눈 | 화면에 눈이 내리고, 영수증 윗변에 닿은 눈은 그 자리에 조금씩 쌓임 |
| 날짜 도장 | 지금은 「영업 중 D-36」, 12월 17일부터 「마감 임박」, 해가 바뀌면 「영업 종료」 (확장 아이디어) |
| 인쇄 | `@media print`로 영수증만 58mm 폭으로 |
| 이미지 저장 | 같은 줄을 58mm 감열 프린터 폭(384점) 비율의 그림으로 다시 그려 PNG로 |

프롬프트는 IntersectionObserver로 줄이 나타나게 하라고 했다. 대신 화면을 그릴 때마다 "다음 줄이 화면에 들어왔는지"를 직접 확인했다. 영상을 만들 때 시간을 1/30초씩 직접 움직이는데, IntersectionObserver는 알림이 언제 올지 정확히 정할 수 없어서 영상이 매번 조금씩 달라질 수 있기 때문이다.

## 막힌 점과 해결

| 막힌 점 | 해결 |
|---|---|
| 날짜 도장이 「영업시간 2026.01.01 ~ 2026.12.31」 글자를 덮음 | 도장을 첫 분류 줄([만든 것]) 오른쪽 빈자리로 옮김 |
| 영상에서 위아래 안내 글자 뒤로 영수증 글자가 비쳐 보임 | 글자 띠를 불투명하게 하고, 영수증은 그 사이 창으로만 지나가게 |
| 영상에서 도장이 늦게 나와 안 보임 | 바코드가 아니라 첫 분류 줄이 찍힐 때 도장도 찍히게 |
| 외부 글꼴(Google Fonts)을 새로 씀 | 사이트 개인정보처리방침에 Google Fonts 접속과 공유 링크 안내를 추가 |

## 영상

첫눈이 내리는 가운데 영수증이 프린터 소리와 함께 한 줄씩 출력되며 아래로 흘러가고, 끝에서 「✂️ 뜯어가기」로 절취선 아래가 떨어지면서 연락처 카드가 나온다. 프린터 소리는 [4편](/blog/today-ai-works-4-kimjang-conveyor/)처럼 페이지의 소리 함수를 OfflineAudioContext로 그대로 합성해 넣었다.

## 배운 점

- 아이디어가 "내 소개"여도, 공개 사이트에 올릴 때는 **누구의 정보가 나가는지**부터 봐야 한다. 도구로 바꾸니 개인정보 문제도 사라지고 방문자가 할 일도 생겼다.
- 영수증처럼 칸을 맞추는 화면은 "대충 2칸"이 아니라 실제 폭을 재야 깨지지 않는다.
- 영상으로도 만들 화면은 애니메이션을 시간으로 직접 움직이게 짜 두면 편하다.
