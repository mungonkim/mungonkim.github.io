## 오늘 한 일

지난 글에서는 카드뉴스를 **손으로 한 편** 만들었다. 오늘은 그 과정을 **매일 자동으로 돌아가는 구조**로 바꾸고, 인스타그램 계정을 만들어 첫 게시물까지 올렸다.

1. 카드 규격을 인스타 격자에 맞게 바꾸기
2. 카드에 들어갈 이미지의 퀄리티 높이기
3. 기사 선정부터 알림까지 자동으로 돌아가는 구조 만들기
4. API 키와 슬랙 연결하기
5. 한 번 실행해 보고, 나온 카드를 고치기
6. 인스타그램 계정 만들고 첫 게시물 올리기

## 1. 카드가 격자에서 잘려 보였다

첫 게시물을 올리고 프로필을 봤더니, 격자의 작은 미리보기에서 카드 왼쪽 글자가 잘려 보였다. 게시물을 열면 멀쩡했다.

원인은 **비율**이었다. 카드를 4:5(1080×1350)로 만들었는데, 인스타그램 프로필 격자는 3:4로 보여 준다. 그래서 좌우가 조금씩 잘린다. 카드를 **3:4(1080×1440)** 로 다시 만들어 격자에 꽉 맞게 했다. 같은 이미지를 한 번 올리고 나서야 알게 된 점이다.

## 2. 이미지가 옛날 AI 느낌이었다

참고 계정의 이미지와 우리가 만든 이미지를 나란히 놓고 보니 차이가 컸다. 정리해 보니 원인은 이랬다.

| 우리 이미지 | 참고 이미지 |
|---|---|
| 소재가 여러 개 흩어져 있다 | **주인공 하나**를 크게 보여 준다 |
| "3D, 파스텔" 같은 뭉뚱그린 스타일 말 | **카메라, 조명, 질감**이 구체적이다 |
| 물건이 떠 있을 뿐이다 | **누가 무엇을 하는 순간**이 있다 |
| 밋밋한 단색 배경 | 공간감이 있고 초점이 흐려진다 |

그리고 이번 뉴스의 주제(ChatGPT가 계산기까지 만들어 준다)에 맞춰 **같은 소재(더치페이 계산기)로 이야기가 이어지게** 했다. 처음에는 기온 그래프 이미지가 나왔는데, 뉴스 주제와 어긋나서 계산기 이미지로 바꿨다.

AI 이미지 도구에 이렇게 요청하면 퀄리티가 좋아진다.

```text
카드뉴스 중간 장에 넣을 이미지를 만들어 줘.
- 주제는 "{기사의 핵심 변화}"야.
- 주인공은 하나만 두고, 누가 무엇을 하는 순간인지 구체적으로 그려 줘.
- 사진처럼 보이게, 카메라(렌즈, 각도), 조명, 분위기를 정해 줘.
- 화면 속 글자는 한글 한두 단어만 쓰고, 나머지는 흐릿한 줄로 표현해 줘.
- 워터마크와 만화 같은 3D 느낌은 넣지 마.
```

## 3. 매일 자동으로 돌아가는 구조

노트북이 꺼져 있어도 돌아가야 해서, **GitHub Actions**(깃허브의 클라우드 실행 기능)로 매일 정해진 시간에 실행되게 했다. 하는 일은 이렇다.

```text
매일 오전 8시(한국 시간)
 1. 공식 블로그와 IT 매체의 RSS에서 기사 후보 모으기
 2. 후보 중 오늘 다룰 기사 1건 고르기 (일상 영향, 공식 발표 여부, 설명하기 쉬운지)
 3. 공식 원문으로 사실 확인하기 (확인하지 못한 내용은 카드에서 빼기)
 4. 카드 7장과 게시물 문구, 이미지 장면 쓰기
 5. 이미지 만들기
 6. 카드 이미지로 저장하기
 7. 슬랙으로 보내기 (오류가 나도 슬랙으로 알려 준다)
```

여기서 가장 신경 쓴 부분은 **사실 확인**이다. 카드뉴스에서 가장 위험한 건 틀린 내용을 올리는 것이어서, AI가 쓴 내용이 아니라 **공식 원문에서 확인한 사실만** 카드에 쓰게 했다. 확인하지 못한 내용은 따로 목록으로 남겨서 슬랙으로 같이 보낸다. 사람이 올리기 전에 한 번 더 볼 수 있게 하려는 것이다.

이런 구조는 AI 코딩 도구에 이렇게 요청하면 뼈대를 만들어 준다.

```text
매일 정해진 시간에 AI 뉴스 카드뉴스를 자동으로 만드는 프로그램을 만들어 줘.
- 노트북이 꺼져 있어도 돌아가게 클라우드(GitHub Actions)에서 실행해 줘.
- 기사 후보는 RSS로 모으고, 기사 선정과 카드 작성은 Claude API로 해 줘.
- 기사 내용은 공식 원문으로 확인하고, 확인하지 못한 내용은 카드에 쓰지 말고 따로 알려 줘.
- 이미지는 이미지 생성 API로 만들고, 완성된 카드는 슬랙으로 보내 줘.
- 비밀키는 코드에 쓰지 말고 저장소의 Secrets로 읽어 줘.
```

## 4. API 키와 슬랙 연결

자동으로 돌아가려면 계정 몇 개를 연결해야 했다. 직접 해야 하는 일이라 하나씩 진행했다.

- **Claude API 키**와 **이미지 생성 API 키**: 소액 충전식이다. ChatGPT, Claude 구독과는 **별개의 서비스**라는 점을 몰라서 처음에는 헷갈렸다.
- **슬랙 앱**: 앱을 만들고, 메시지를 보내는 권한과 파일을 올리는 권한을 추가한 뒤 채널에 초대한다.

키는 코드에 적지 않고 **저장소의 Secrets**에만 넣었다. 저장소도 비공개로 만들었다. 키가 한 번 노출되면 다시 발급해야 해서, 이 부분은 처음부터 조심했다.

슬랙 앱을 만들 때 막힌 점이 있었다. 설정 파일(매니페스트)에 권한을 적어 넣었는데 **적용되지 않았다**는 경고가 떴다. 권한 설정 화면에서 직접 추가했더니 해결됐다. 화면이 안내와 조금씩 다를 때는 보이는 화면을 그대로 설명하면 어디를 누를지 알려 준다.

```text
슬랙 앱을 만들어서 봇이 채널에 이미지와 글을 올리게 하고 싶어.
지금 보이는 화면은 "{화면 설명}"이야. 다음에 어디를 눌러야 하는지 알려 줘.
봇 토큰은 대화에 붙여넣지 않고 저장소의 Secrets에 직접 넣을 거야.
```

## 5. 한 번 실행해 보니

저장소 화면에서 직접 실행해 봤다. **2분 34초 만에 끝까지 성공**했고, 슬랙으로 카드 7장과 게시물 문구가 도착했다.

- 후보 기사 102건 중에서 구글의 "신스ID 디텍터"(AI가 만든 이미지, 영상, 음성인지 확인하는 도구) 공개 소식을 골랐다.
- 공식 원문으로 사실 8건을 확인했고, 확인하지 못한 6건은 카드에서 뺐다.
- 직접 해 볼 만한 소식이라서 "체험 후보"로도 표시해 줬다. 다음 프로젝트 과제로 쓸 수 있다.

처음 나온 결과에서 고친 점도 있다.

- 5번 카드는 **위쪽 문구와 제목이 똑같은 문장**으로 두 번 나왔다. 제목을 행동을 알려 주는 짧은 문구로 쓰게 지시를 고쳤다.

## 6. 인스타그램 계정과 첫 게시물

참고 계정처럼 **캐릭터 하나를 프로필 사진으로** 쓰기로 해서, 표지에 쓴 말풍선 캐릭터를 잘라 프로필 사진을 만들어 두었다. 이름은 "AI랑 친해지기"로 하고, 소개글에는 블로그 링크를 넣었다. 계정 종류는 카테고리를 고를 수 있는 프로페셔널(크리에이터) 계정이다.

게시물 문구에는 외국인 독자를 위해 **한국어 아래에 영어 설명**을 함께 넣기로 했다. 시스템이 두 언어를 한 번에 써 준다.

## 배운 점

- **규격은 올려 보고서야 안다.** 인스타 격자는 3:4라는 걸 올려 보고 알았다. 올리기 전에 한 번 확인할 곳을 정해 두었다.
- **AI 이미지는 구체적으로 시켜야 한다.** 스타일 단어만 나열하면 어디서 본 듯한 이미지가 나온다. 누가 무엇을 하는 순간인지, 카메라와 조명까지 정하면 훨씬 낫다.
- **자동화는 알림이 핵심이다.** 매일 사람이 올려야 하는 구조라서, 결과와 확인할 내용이 한곳(슬랙)에 모이는 게 중요했다.
- **결과를 눈으로 확인해야 한다.** 에러 없이 끝났는데 결과가 0건인 경우가 있었다.

## 앞으로

- 내일 아침에 **첫 정식 자동 실행**이 슬랙으로 오는지 확인할 예정이다.
- 자동으로 고른 기사 중 직접 해 볼 만한 것은 **프로젝트 과제로 돌려서**, 해 본 결과를 카드뉴스로 만들 계획이다. (예: 신스ID로 AI 사진과 진짜 사진 가려내 보기)
- 자동 카드가 쌓이면 반응이 좋은 형식과 기사 종류를 정리해서 기준을 고쳐 나갈 것이다.

이 과정도 계속 이 블로그에 기록할 것이다.
